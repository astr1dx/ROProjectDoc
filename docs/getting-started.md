# How to start

Use this handbook to learn Ad Infinitum's classic rules, class adjustments and everyday tools. The game environment is currently local/offline; publishing this wiki does not make the game server public.

## Choose your character

Start with [Server Information](server-rules.md) for rates, level caps, Philippine server time and the Episode 14.2 content profile. Then use [Find Your Class](classes.md) to jump to your class's skill adjustments and platinum skills.

## Set up your preferences

Type **`@settings`** after entering the game. This menu controls pet visibility, song audio, drop notices, card artwork, EXP messages, whisper warnings, day/night and announcements. Most display/chat choices follow your account; storage weight, farming lists and kill-steal protection belong to each character.

Everyone automatically joins **#main**, **#recruit** and **#market** unless they have saved an Off choice. Change visibility in **Channel Config**. See [Personal settings](personal-settings.md) for defaults and how to send channel messages.

[Card exchange](card-exchange.md) uses its own account-wide points. The [vendor system](vendor-system.md) covers Market Street, shop searches and offline vending.
