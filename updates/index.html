    📰 Latest updates¶

    Dated notes record changes to the game server and this handbook. For complete current rules, follow the linked feature guides.

    2026¶

    November 13¶

    Vestige Rift, independent baby characters and Build Manager

    • A new server and handbook identity: Vestige Rift.
    • Sister Elara's 5,000,000z adoption-free conversion, temporarily at Prontera 136,196.
    • Preserved character progress, baby second-job progression and the permanent Baby Novice restriction.
    • Build Manager at Prontera 154,193: ten stat and ten skill slots per character, free saving and 5,000z loading, with class/level safeguards.

    Read the November 13 update.

    November 11¶

    Homunculus and pet commands

    • Enabled current/growth stat commands and companion speech for ordinary players.
    • Added owner-attributed chat logging for companion speech and supported pet emotes.
    • Applied Mute Pets and Hide Pets to pet speech and emotes without suppressing homunculus or player chat.

    Read the November 11 update.

    November 10¶

    Personal settings, hunting tools and market updates

    • Saved preferences through @settings, song muting and default server channels.
    • Per-character autoloot thresholds, ignore lists and custom groups.
    • Restock target lists and item-only Quick Store that deposits all eligible units.
    • Confirmed single-monster Kill Count tracking with private, name-free overhead counts.
    • Short card-find announcements with actual-looter credit and Public chat filtering.
    • Per-character kill-steal protection with Self/Party/Guild modes and party checks.
    • Long trade-search aliases: @whosell, @whosell2, @whobuy and @whobuy2.
    • Safer handling of ignored ground drops and a reorganized topic-based handbook.

    Read the November 10 update.
